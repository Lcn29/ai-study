# Linear、激活与 MLP：模型怎样加工一组数字

文字变成 Token ID，再查成向量之后，模型怎样继续加工这些数字？

先看《AI学习目录》第 04 课的一条完整教学路径：

```text
[2,−1] → [1,−2,3] → [1,0,3] → [1,−2]
```

第一步把两个输入组合成三个数；第二步把负数截成零；第三步继续组合，得到两个输出。这里每一步都有明确的规则，不是看着数字随意改写。

这篇文章对应第二阶段“看懂 Transformer 的零件”中的第 04 课“Linear、激活与 MLP”，依据《32课学习设计与掌握目标》组织。读完并独立完成检查后，你应能：

1. 分开本次输入、模型参数和计算输出，知道普通推理使用已有参数。
2. 说明每个输出怎样组合多个输入。
3. 指出 ReLU 在哪一步引入非线性，并解释为什么只堆 Linear 不够。
4. 解释 ReLU 的非负输出为什么仍能经过后续 Linear 变成负数。
5. 分清 FFN 的逐位置加工与注意力的跨位置汇总。

最低前提是会读数字列表，能做含负数的加减乘。矩阵符号放在选读，不需要先会编程。全文参数、折线和练习来自课程教学设置或沿其规则推演，**不代表真实模型的测量结果**。

## 先补必要的一步：本课加工的是向量

向量在这里就是一组按顺序排列的数。`[2,−1]` 有两个坐标，所以是二维向量。它可以作为某个 Token 位置的表示进入后续计算。

本节从这组数开始，不再处理 Token 的编号。模型既可以加工查表得到的初始表示，也可以加工前面层已经计算过的表示。我们没有为这两个坐标指定“情绪”或“语义”等标签；算出一个负数，也不表示模型对某件事持否定态度。

要学会本节，先盯住三个问题：**输入是什么，规则是什么，输出怎样算出来**。

## 一、Linear：按参数组合输入，再加偏置

### 先从一个输入算起

课程的最小例子是：

```text
输入：x = 2
计算规则：y = 3x + 1
代入：y = 3×2 + 1 = 7
```

这里的 `2` 是本次输入，`7` 是本次输出。乘在输入前面的 `3` 叫 **Weight，权重**；额外加上的 `1` 叫 **Bias，偏置**。权重与偏置属于这层的**参数**。[^线性]

| 对象 | 本例中的值 | 换一次输入会怎样？ |
| --- | --- | --- |
| 输入 | `2` | 可以换成另一组数据 |
| 权重 | `3` | 固定参数推理时继续使用它 |
| 偏置 | `1` | 固定参数推理时继续使用它 |
| 输出 | `7` | 根据输入与参数重新计算 |

例如保持规则不变，把输入改成 `−1`：

```text
y = 3×(−1) + 1 = −2
```

变的是输入与结果，权重仍是 `3`，偏置仍是 `1`。**算出新结果，不等于更新了参数**。

模型训练会根据数据、目标和训练方法更新参数；普通推理使用已有参数完成计算。本课先学“按参数怎样算”，训练怎样调整参数留到第 24 课。[^训练]

### 名叫 Linear，带偏置时严格属于仿射变换

深度学习里常把这种模块叫 **Linear，线性层**。严格地说，只做加权组合的是线性变换，加上偏置后叫**仿射变换**。PyTorch 的 Linear 官方定义也明确包含这个区别。[^线性]

暂时不用背这个数学名称。理解为“按系数组合输入，再加一个偏移”就能继续算。后文说纯 Linear 串联仍是同类变换，会同时保留有偏置的情况。

## 二、两个输入怎样产生三个输出？

刚才只有一个输入。现在回到主例：

```text
输入：[2,−1]
```

记第一个输入为 `x₁=2`，第二个为 `x₂=−1`。下标只是在数坐标，不是新的输入。

第一层要产生三个输出。每个输出各有一组权重和一个偏置，课程完整给定如下：

| 输出坐标 | 乘 x₁ 的权重 | 乘 x₂ 的权重 | 偏置 | 计算规则 |
| --- | --- | --- | --- | --- |
| 第 1 项 | 1 | 1 | 0 | `x₁+x₂` |
| 第 2 项 | −1 | 1 | 1 | `−x₁+x₂+1` |
| 第 3 项 | 2 | 0 | −1 | `2x₁−1` |

逐行代入：

```text
第 1 项：2×1 + (−1)×1 + 0 = 1
第 2 项：2×(−1) + (−1)×1 + 1 = −2
第 3 项：2×2 + (−1)×0 − 1 = 3

第一层结果：[1,−2,3]
```

你可以看到，第 1、2 项都同时用了两个输入。第 3 项的第二个权重恰好是零，所以这一项没有受到第二个输入的影响。

这就是 Linear 的加权组合：**每个输出可以使用多个输入坐标，不要求只给对应项乘一个数**。有些权重为零时，相应输入就没有贡献；“可以组合多个输入”也不等于每个输出必须用到全部输入。[^线性]

这一层把二维变成三维。改变的是表示里有多少个坐标，不是把两个 Token 变成三个 Token。主例一直在加工同一个位置的一组数。

## 三、ReLU：在哪一步把负数变成零？

### 先认规则，再看名字

第一层结果是 `[1,−2,3]`。接下来对每一项执行相同规则：

- 小于零，换成零。
- 等于零或大于零，保持原值。

于是：

```text
1  → 1
−2 → 0
3  → 3

[1,−2,3] → [1,0,3]
```

这项处理叫 **ReLU，修正线性单元**，公式写成 `ReLU(值)=max(0,值)`。`max` 就是选较大的那个数。它按坐标逐项处理，**改变数值，保持形状**。[^激活]

把 `−1、0、1` 分别送进去，得到 `0、0、1`。输入在零以下时输出停在零；到了零以上，输出开始随输入增加。规则在零处出现了折点，这就是本课用来观察的**非线性**。

这样的处理称为 **Activation，激活函数**。它提供区别于纯加权和加偏置的非线性变化。本课采用的 ReLU 规则本身没有要训练的权重或偏置；不能据此推广为所有激活形式都没有可训练参数。

### 把结果送入第二层

ReLU 的三个输出记为 `h₁、h₂、h₃`，当前分别是 `1、0、3`。第二层使用课程的固定规则：

| 输出坐标 | 乘 h₁ 的权重 | 乘 h₂ 的权重 | 乘 h₃ 的权重 | 偏置 | 计算规则 |
| --- | --- | --- | --- | --- | --- |
| 第 1 项 | 1 | 2 | 0 | 0 | `h₁+2h₂` |
| 第 2 项 | 0 | 1 | −1 | 1 | `h₂−h₃+1` |

逐项计算：

```text
第 1 项：1×1 + 0×2 + 3×0 + 0 = 1
第 2 项：1×0 + 0×1 + 3×(−1) + 1 = −2

最终结果：[1,−2]
```

**ReLU 后的非负数，不保证后续 Linear 输出非负**。这里第二项的权重包含 `−1`，非负的 `3` 被减掉，加上偏置后仍是负数。

如果这次计算还在最后接一个 ReLU，`[1,−2]` 才会再变成 `[1,0]`。但课程主例到第二个 Linear 为止，没有这一步，不能自行把最终负数截掉。

### 接起来，就是一个小 MLP

**MLP，Multi-Layer Perceptron，多层感知机**，通过连接多个 Linear，并在中间加入非线性处理来加工表示。本例是一个 `2→3→2` 的小 MLP：两个输入坐标，三个中间坐标，两个输出坐标。[^原讲解]

```mermaid
flowchart LR
    A["输入：2 个数"] --> B["第一层 Linear：组合成 3 个数"]
    B --> C["ReLU：逐项处理，仍是 3 个数"]
    C --> D["第二层 Linear：组合成 2 个数"]
    D --> E["输出：2 个数"]
```

“层多”只是在描述结构。接下来要看：中间的非线性究竟改变了什么。

## 四、为什么十层纯 Linear 也不会自动出现折点？

### 先在同一主例里拿掉 ReLU

第一层仍得到 `[1,−2,3]`。如果不经过 ReLU，直接进入原来的第二层：

```text
第 1 项：1 + 2×(−2) = −3
第 2 项：−2 − 3 + 1 = −4

没有 ReLU：[−3,−4]
有 ReLU：  [1,−2]
```

这一差别来自中间的 `−2` 被截成零。参数没有改，输入没有改，改变的是处理步骤。

但只看到两个结果不同，还不足以解释非线性。再用一维关系看看“折点”意味着什么。

### 两层仿射可以合成一层

假设先算 `3x+1`，再把结果乘 `2`、加 `4`：

```text
第一层：t = 3x + 1
第二层：y = 2t + 4

代入：y = 2×(3x+1) + 4
       = 6x + 6
```

两层可以合成一次“乘 `6`、加 `6`”。一维画出来仍是一条直线。继续串联更多固定参数的纯 Linear／仿射层，仍可以合并为同类变换。这个结论针对中间没有其他非线性操作的串联结构。[^原讲解]

### ReLU 可以让规则在不同输入区间改变

课程进一步给出：

```text
f(x) = ReLU(x) − 2×ReLU(x−1)
```

沿同一个 ReLU 规则计算：

| 输入 x | ReLU(x) | ReLU(x−1) | 最终 f(x) |
| --- | --- | --- | --- |
| −1 | 0 | 0 | 0 |
| 0 | 0 | 0 | 0 |
| 0.5 | 0.5 | 0 | 0.5 |
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 0 |

例如输入 `2`，先得到 `ReLU(2)=2`，另一路得到 `ReLU(1)=1`，再算 `2−2×1=0`。

这条关系在零以下保持水平；零到一之间上升；超过一后下降。在 `0` 和 `1` 处改变了斜率，有两处折点。

只看其中三个点就能检查它不是单条直线：输入 `0、1、2`，输出是 `0、1、0`。两次输入都增加 `1`，输出却先增加 `1`、再减少 `1`，不是固定斜率。

**激活扩展了可表达的关系，但不保证任务效果更好**。是否适合任务，还需要数据和评估；不能把折点、层数或参数数量直接当成正确率。

本课用 ReLU 说明机制。原始 Transformer 的前馈子层使用 ReLU，后来的模型可以使用其他激活或门控结构；看到 MLP 或 FFN，不能未经核对就断定中间一定是 ReLU。[^前馈]

## 五、FFN 加工哪个位置，Attention 汇总哪些位置？

**FFN，Feed-Forward Network，前馈网络**。在本课的 Transformer 语境里，它指每个位置分别应用的前馈子层，原始结构就是“两次 Linear，中间 ReLU”。同一层的各位置共用一组参数，各层之间则可以使用不同参数。[^前馈]

假设有两个位置，其当前表示分别是：

```text
位置甲：[2,−1]
位置乙：[−1,2]
```

沿用本篇 MLP 作为教学 FFN，各位置分别加工：

```text
甲：[2,−1] → [1,−2,3] → [1,0,3] → [1,−2]
乙：[−1,2] → [1,4,−3] → [1,4,0] → [9,5]
```

两处使用相同规则，但输入不同，结果可以不同。没有把甲的第一项与乙的第二项拼起来算，也没有在 FFN 这一步求两个位置的平均。

| 本课比较的部分 | 计算时怎样使用表示？ |
| --- | --- |
| 逐位置 FFN | 每个位置使用同一组参数，加工自己的输入向量 |
| Attention，注意力 | 根据可见范围，把其他位置的信息汇入当前位置 |

这里区分的是**直接计算发生在哪一步**。FFN 的输入可能已经由之前的注意力汇入上下文，所以“逐位置加工”不等于“这个位置永远不受其他位置影响”。[^前馈]

下一课会展开 Attention 如何匹配、分配权重和汇总。此处只需把两种职责分开，不需要提前计算注意力公式。

### 检查 2：换输入，沿同一 MLP 算完

### 检查 3：纠正“最终只能非负”的推断

有人说：“ReLU 已经把所有负数去掉，所以第二层只能输出非负数。”

用主例第二层的第 2 项，写出反例算式。若最后额外接一个 ReLU，输出会怎样？课程主例是否包含这一步？

### 检查 4：层数与非线性分开判断

先计算 `t=2x−1`，再计算 `y=3t+2`。把两层合成关于 `x` 的一个式子，判断它有没有由这两层产生折点。

再看课程折线的三个点：`(0,0)、(1,1)、(2,0)`。为什么单条直线不能同时通过它们？本课哪项操作使不同区间有了不同规则？

### 检查 5：两个位置是否需要混在一起？

位置甲和乙分别输入 `[2,−1]`、`[−1,2]`，使用本篇同一套 FFN 参数。

写出两个位置的最终结果。假如只把乙的输入替换成 `[2,−1]`，保持甲的输入和所有参数不变，甲在**这一次纯逐位置 FFN 计算**中的结果是否改变？

“FFN 逐位置计算，所以它的输入一定没有上下文”这句话哪里有问题？

## 七、参考答案与达标标准

### 检查 1 的答案

输入是 `4`，权重是 `3`，偏置是 `1`，输出是 `3×4+1=13`。

输出改变是重新计算的结果，没有证明参数更新。把规则改成 `5x+1`，是权重由 `3` 改为 `5`；但仅从这句话不能确定它是训练更新还是人为改写。

**过关点**：分别指出数据、参数和结果，知道普通推理使用已有参数，不把结果变化当作训练证据。

### 检查 2 的答案

第一层：

```text
第 1 项：(−1)×1 + 2×1 + 0 = 1
第 2 项：(−1)×(−1) + 2×1 + 1 = 4
第 3 项：(−1)×2 + 2×0 − 1 = −3
结果：[1,4,−3]
```

ReLU 逐项处理：

```text
[1,4,−3] → [1,4,0]
```

第二层：

```text
第 1 项：1 + 2×4 = 9
第 2 项：4 − 0 + 1 = 5
结果：[9,5]
```

`−3` 在 ReLU 步骤变为零。第一层把同一位置的两维表示变成三维，没有增加 Token 位置数。

**过关点**：多输入组合与每步结果正确，准确定位非线性发生的步骤。

### 检查 3 的答案

主例 ReLU 后为 `[1,0,3]`，第二层第 2 项是：

```text
h₂−h₃+1 = 0−3+1 = −2
```

后续 Linear 有负权重，可以从非负输入产生负数。若末尾额外加 ReLU，最终 `[1,−2]` 会变成 `[1,0]`；但这是额外步骤，主例没有它。

**过关点**：用实际算式纠正推断，并以明确结构判断是否还要截断。

### 检查 4 的答案

```text
y = 3×(2x−1) + 2 = 6x−1
```

仍是一维仿射关系，没有因纯 Linear 串联产生折点。

三个折线点的相邻输入增量都是 `1`，输出增量却分别是 `+1` 和 `−1`。单条直线的斜率固定，不能同时满足它们。课程关系中的 ReLU 引入分区间处理，令组合后的斜率可以改变。

**过关点**：能合并两个仿射步骤，并用输入输出变化解释折点，不用“网络更深”代替理由。

### 检查 5 的答案

甲输出 `[1,−2]`，乙输出 `[9,5]`。只更改乙的输入，在甲输入与参数都固定的这次逐位置 FFN 计算中，甲仍输出 `[1,−2]`；乙改为与甲相同的输入后，也输出 `[1,−2]`。

FFN 这一步不直接汇总其他位置，但进入它的向量可以已经由前面 Attention 融合上下文。对整套模型重新计算时，其他环节的影响需要另外分析，不能把这个局部结论推广为全部层都互不影响。

**过关点**：分清共享参数、分别计算和跨位置汇总，并保留输入已有上下文的边界。

## 八、可选进阶：把算式排成矩阵，数清形状与参数

### 矩阵只是把已有系数排成表

回看第一层参数，把每个输出对应的权重排成一行：

```text
第一层权重：
[
  [ 1, 1],
  [−1, 1],
  [ 2, 0]
]
第一层偏置：[0,1,−1]
```

这张三行两列的数字表叫**矩阵**，形状记为 `(3,2)`：三个输出，每个输出对两个输入各有一个系数。它压缩记录了第二节的逐项计算，并没有换一套规则。

PyTorch 把 Linear 的权重形状写成“输出维度 × 输入维度”，公式采用 `y=xAᵀ+b`。这里 `A` 是权重表，`b` 是偏置；`Aᵀ` 表示行列交换后的表，用来配合这一行向量写法。首遍理解仍以逐项算式为准。[^线性]

第二层同样排成：

```text
第二层权重：
[
  [1,2, 0],
  [0,1,−1]
]
第二层偏置：[0,1]
```

两行三列，形状是 `(2,3)`，与三个中间坐标、两个输出坐标相配。

### 哪个维度变了，哪个没有变？

假如一起处理两条序列，每条有四个位置，每位置有两个数，输入形状就是 `(2,4,2)`：批次、位置、坐标。

本例的变化是：

| 步骤 | 形状 | 变化 |
| --- | --- | --- |
| 输入 | `(2,4,2)` | 每位置两个坐标 |
| 第一层 Linear 后 | `(2,4,3)` | 每位置改为三个坐标 |
| ReLU 后 | `(2,4,3)` | 改数值，形状不变 |
| 第二层 Linear 后 | `(2,4,2)` | 每位置回到两个坐标 |

Linear 改变最后一维，批次与位置维度保持不变；ReLU 保持全部维度不变。这里假定输入已排成表中等长的序列，不展开补齐规则。[^线性][^激活]

### 本例有多少参数？

数权重表里的每个位置，再加偏置数：

```text
第一层：3×2 个权重 + 3 个偏置 = 9
第二层：2×3 个权重 + 2 个偏置 = 8
合计：17 个参数
```

零值系数也算一个已定义的参数位置；数的是这两层带偏置结构的参数槽位。ReLU 本身没有增加可训练数。每个位置重复使用同一套参数，所以本例处理更多位置不会把这 `17` 乘以位置数。

这些数是课程小模型的结构计数，不是完整 Transformer 参数量；也不能由 `17` 个参数推出真实任务效果。
