# AI 学习引导

本引导依据《AI学习目录》的 12 个阶段、32 节课编排，连接 `lesson/` 目录中的 **32 篇课文与 12 篇阶段串讲**。小节名称沿用学习目录，阅读链接指向现有 Markdown 正文；两者的标题有措辞差异，课程编号一致。

课程围绕一个贯穿问题展开：怎样让知识库助手给出有依据的答案，并在处理资料时遵守权限、留下可核验的结果？前面理解模型，中间学习任务表达、上下文、证据与执行，后面理解训练、成本和多模态，最后完成综合验收与专题研究。

## 怎样使用这份引导

1. 先看当前阶段的先修要求，按编号阅读课文，跟着例子解释每一步的输入、变化和输出。
2. 合上正文，独立完成课文中的练习或自测，再对照答案与达标标准。首遍可暂缓可选进阶与公式推导。
3. 读完本阶段的小节，再读阶段串讲，把各小节接成一条连续过程。串讲用于整合与回顾，不代替独立练习。
4. 按本引导的阶段过关要求交出一张图、一份记录或一个可检查的结果。遇到错误，回到对应小节及文末“依据与回查”，通过后再继续。

第 07 课开始就使用第 16—18 课的成功标准与验收方法；不必等到第六阶段才检查自己的答案。课程中的数字、设备规则和模拟动作均按各课明确的教学条件理解，不作为真实模型成绩或现实业务制度。
